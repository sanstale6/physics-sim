# 高中物理模拟器 — 设计草案

## 1. 定位

面向高中生/教师的 2D 物理实验沙盘：像做真题图一样用简约线条元件搭场景，
运行后实时观察受力与运动。纯前端 SPA，serverless 部署。

## 2. 设计原则

1. **元件即真题图元**：物块、斜面、滑轮、弹簧、绳、点电荷、平行板、
   磁场区域、光线、透镜……每个元件的视觉都要像教辅/试卷里的画法（线框 + 符号）。
2. **物理量显式**：坐标以米为单位（100px = 1m），g = 9.8 m/s²，
   面板输入与显示均用物理单位；矢量（力/速度/加速度）可开关显示。
3. **场景可保存**：场景序列化为 JSON（localStorage + 导入/导出文件），
   内置"真题预设"（平抛、斜面滑动、带电粒子圆周、碰撞验证动量等）。
4. **注册表架构**：一切元件在 registry.js 登记（defaults/body/overlay/force），
   引擎只认类型不认具体元件，新增元件零侵入。

## 3. 模块划分

| 模块 | 职责 |
|---|---|
| sim/registry.js | 元件注册表：defaults / body / overlay / force 钩子 |
| sim/engine.js | matter-js 世界 + 每帧自定义力（恒力、洛伦兹、库仑…） |
| sim/presets.js | 内置真题场景（JSON） |
| hooks/useSim.js | React 状态桥接：add/remove/update/reset/时间 |
| components/SimCanvas | 渲染 + pointer 交互（放置/拖拽/选择/删除） |
| components/Inspector | 属性面板（按 registry 的字段描述自动生成） |
| components/Vectors | 力/速度/加速度矢量叠加层 |
| components/SceneIO | 保存/载入/导出 JSON、预设列表 |

## 4. 元件字段描述（Inspector 自动化）

registry 每个元件附 `fields: [{key, label, min, max, step, unit}]`，
Inspector 据此生成滑条/数字框，避免硬编码。

## 5. 力学模型（单位约定）

- 世界坐标：像素；SCALE = 100 px/m。matter 质量 = kg（Body.setMass 显式设定）。
- 力：F_matter = F_N * 0.001（调参使 10N 恒力对 1kg 物块产生约 10 m/s² 加速度）。
- 洛伦兹力：F = q v × B，q 单位 μC、B 单位 T、v 由 body.velocity * SCALE 换算 m/s。
- 库仑力：F = k q1 q2 / r²，作用于两个点电荷刚体之间。
- 斜面：静态多边形；物块在斜面上的摩擦由 matter 处理；θ 显示在斜面上。

## 8.1 受力分析（M8）

选中任一物块/小球后，画布叠加：

| 矢量 | 颜色 | 计算 |
| --- | --- | --- |
| 重力 G | 橙 | `mg`，屏幕向下 |
| 支持力 N | 绿 | 斜面：`mg·cosθ`（法线方向）；地面：`mg` |
| 摩擦力 f | 红 | 斜面：`μN`（动）或 `min(μN, |T|)`（静）；地面同理 |
| 恒力 F | 蓝 | 恒力元件参数 `(Fx, −Fy)`（Fy 正为上） |
| 合力 F合 | 黄加粗 | 上述矢量和，附 `a = F合/m` |

- 重力矢量固定 55px，其余按 `55/mg` 的比例缩放，便于比较大小。
- 斜面接触时额外画虚线分解：沿斜面 `mg·sinθ` 与垂直斜面 `mg·cosθ`。
- 实现：`src/sim/analysis.js`（纯函数，可单测）+ `src/components/Vectors.jsx#drawForceAnalysis`；工具栏「受力」按钮开关。

## 8.2 直流电路（M9）

- 元件：电源 E/r、定值电阻、滑动变阻器、小灯泡、开关、电流表、电压表、导线。每个元件是一只**两端元件**，两端子位于 `(x,y) ± len/2·(cosθ, sinθ)`。
- 连接方式：端子坐标重合（容差 12px）即视为同一节点；放置新元件时自动吸附到最近端子（26px 内），因此三只元件共用一点即可形成 T 形分支。
- 求解：节点电压法。电池按 Norton 等效处理（`I=ε/r` 电流源 ∥ r），避免理想电压源导致的矩阵奇异；每个节点对地并入 1e-9 S 防悬空；高斯消元（列主元）。
  - 电阻表：导线 1e-3 Ω、电流表 1e-2 Ω、电压表 1e6 Ω、闭合开关 5e-3 Ω、断开 1e12 Ω。
  - 电流正方向 a→b；电表读数 = 两端电压 / 内阻。
- 验证：串联 ε=6 V、r=0.5 Ω、R=10+20 Ω → I=0.1967 A；并联两只 20 Ω → I总=0.5713 A、支路 0.2857 A，与手算一致。
- UI：元件上自动标注数值与电流方向箭头；小灯泡有电流时发亮；开关闭合/断开在属性面板切换。
- 实现：`src/sim/circuit.js`（纯函数，可单测）+ registry 内 `drawCircuit` 绘制。
- 功率与告警：每个电阻/灯泡算 `P=I²R` 并标在元件下方；无电流元件半透明灰显；状态栏显示总功率与告警
  - 短路：`|I_电源| > 0.75·ε/r` → 「电流接近 ε/r，疑似短路」
  - 断路：全部支路无电流但有电源 → 「电路未闭合」；部分元件无电流 → 「N 个元件无电流（断路）」
- 自测样例：短路 ε=6/r=0.5 → I=11.98 A；断开开关 → P=0；闭合 → I=0.5711 A、P=3.263 W（手算 6/10.5 ✓）。

## 13. 交互与工程补充（第二轮打磨）

- 手势：`idle | pan | press | drag | pinch` 状态机（SimCanvas），单指拖空白 = 平移视角，双指 = 缩放 + 平移；触摸命中容差 18/scale，鼠标 6/scale
- 相机：`view = { scale, tx, ty }`，缩放 0.3–4×，右下角 ⤢ 显示全部 / ＋ － / ⟲ 复位（CustomEvent `sim-fit` / `sim-zoom` / `sim-zoom-reset`）
- 恢复初始条件：`home` 记录位置与角度，拖动即更新 `home`，重置回到 `home` 并重放初速度 v0
- 连接关系：绳 / 弹簧 / 滑轮 / 单摆放置时记下最近的动态物体（`props._a/_b`），避免多物体场景里「最近两体」随运动变化导致跳绑；导出场景时丢弃该内部字段
- 旋转：属性面板统一提供「旋转 (°)」字段，非刚体元件写 `props.angle`（电路端子、光学追迹都读它），刚体同时 `Body.setAngle`
- 重力开关：`engine.js` 导出 `gravityState.on`，关闭时 `engine.gravity.y = 0`，带电体也不再抵消重力（失重演示）
- 读数：属性面板显示 v / x / y（刚体）或 I / U / P（电路元件）；磁场区域内直接标注 r = mv/qB 与 T = 2πm/qB
- 分享：`src/sim/share.js` 把场景 JSON 编成 base64url 放进 URL 的 `#scene=`，纯静态部署也能分享；App 挂载时自动载入
- 截图：`SceneIO` 里 `canvas.toDataURL()` 直接下载 PNG（只含画布，不含 UI）
- 空场景提示：画布中央提示「从下方元件栏选一个元件」+ 预设入口
- 帮助：顶部 ❓ 打开操作说明表格（手势、按钮、单位约定）

## 15. 电路交互：并联态与重叠选中（第 15 轮）

### 15.1 重叠元件轮换选中
点在同一位置时，命中测试返回**该点所有命中元件**（`hitTestAll`，hit.js）。选择模式下连续点击同一点（16px 内、命中集合不变），按「后放的在最上层 → 先选中」的顺序循环：
放置顺序 3,6,4 → 点击顺序 6,4,3,6,4,3…。换位置或命中集合变化即从第一个（最上层）重新开始。

### 15.2 并联态
待放置元件 B 与既有连接点对 A1A2 满足三条时进入**并联态**（`findParallel`，circuit.js）：
1. `|len(A1A2) − len(B)| ≤ max(30, 0.4·len(B))`
2. 角度差（mod π，π+θ 与 θ 等价）≤ 14°
3. 中心到 A1A2 的垂直距离 ≤ 150px，且沿轴投影偏离中点 ≤ max(45%, 60px)

对齐方式：元件长度与角度取 A1A2，中心**沿轴归位到 A1A2 中点、保留垂直偏移**（所以两条引线等长且垂直）。
- 预览态（悬停）：对齐后的元件画成青色虚线，两条引线灰色半透明，并标注「XX（并联）」。
- 落定后：`props._par = { a1, a2 }`。绘制时补两条灰色引线；电气连接点由 `connPins(o)` 返回 A1A2，所以电路求解把元件两端当作接在 A1A2 上——**元件数仍然只有 1 个**，引线不是独立导线。
- 解除：拖动元件或改长度/角度时删除 `_par`，恢复普通形态（不再连在那对节点上）。
- `_par` 是纯数值对象，可随场景 JSON 存档与分享链接一起序列化。

### 15.3 螺线管接入电路
`resistance()` 补 `solenoid: max(0.1, R ?? 2)`。此前该分支返回 `null`，`1/null = Infinity` 会让整条电路的节点矩阵变成 NaN，表现为「螺线管无法接入 / 整条电路无电流」。

### 15.4 纯导线样式
`wire` 不再画「两段引脚 + 中间 32px 缺口」，改为整条实线连通。

## 16. 电磁感应与电路扩展（第 16 轮）

### 16.1 金属棒 metalRod（替代 rail）
- 动态刚体（rotRect + `inertia: Infinity`，防安培力矩转动），端子取 `body.position/angle` 而非 props（棒会滑动）
- 电动势：ε = B·L(vx sinθ − vy cosθ)，B 为棒处 uniformB 之和（内部约定 B_eff=(0,0,−bz)，与电荷洛伦兹力同号，楞次定律自动成立）
- 安培力：Fx = −I·L·B·sinθ、Fy = I·L·B·cosθ → 阻碍相对运动
- 滑动接触：clusterNodes 里「端子压在线段中段」规则**仅对 metalRod** 生效，避免其它元件端子把电路短接
- 注意：applyForces 每步只能调用一次（body.force 累加）

### 16.2 二极管 / 多用电表
- diode：正向 1e-2Ω、反向 1e12Ω，用 `_on === false` 表示截止；solve 末尾做一次方向迭代（重解后清临时标记保缓存）
- multimeter：档位 mode 0=A(0.1Ω)/1=V(1e6Ω)/2=Ω(1e12Ω)，Ω 档靠端子重合找被测电阻标称值

### 16.3 交流电源
- battery props `ac/freq`；useSim 每物理步写 `_eInst = E·sin(2πft)`，切回直流时删除 `_eInst`；solve 缓存 key 含 `_eInst`，面板/灯泡随相位闪烁

## 17. 第 17 轮：交互与演示修正
- 回旋加速器改为极坐标驱动：圆心恒在加速器中心，θ += ω/60（ω=qB/m），跨过 0/π 时按动能定理提 v 并重算 r=mv/(qB)；r≥R 时置 `_cycOut` 放归常规物理直线飞出。好处是轨迹是教科书上的同心半圆，参数量（R/U/B/q/m/v0）都有明确物理含义
- solve 缓存 key 必须覆盖一切影响方程的 props：battery `_eInst/E/r`、metalRod `_eInst/R`、**plates `U`**、switch `closed`、其余 `R`
- 有 overlay 自定义外观且有 matter 刚体的元件（magnet/metalRod/conveyor/pulley）不要再用 drawBody 画一遍
- 电子枪发射计时用「本帧经过的物理时间」，不要用外层累加变量
- 电荷相互作用开关 `coulombState.on` 只关库仑力对（电荷间的成对力），不影响外加场

## 18. 第 18 轮：电容器（RC 暂态）
- 电容器按「储能元件」建模：solve 里把它当电动势源（E=当前 U、r=ESR 0.1Ω），每物理步由 engine 用前向欧拉积分 U += −I·dt/C 更新端电压，形成 RC 充放电暂态
- 电容单位换算：props.C 用 μF（高中量级 20~500），engine 里 `Ceff = C*1e-3` 放大 1000 倍，让 τ=RC 落到秒级可见（10Ω×100μF→1s）；ESR 0.1Ω 只给数值稳定，不参与教学
- 缓存 key 里电容 U 变化必须进 key（`'C'+U.toFixed(6)`），否则充放电过程中 solve 不重算、I 冻结
- 电容 U 有方向（b 端为参考正端）；功率可负表示放电，不计入总功率
- 新增预设「电容充放电」+ scripts/capacitor.mjs 8 断言（充电指数上升、放电指数衰减、稳态电流趋零）

## 19. 第 19 轮：万有引力（开普勒定律）
- gravity 元件（无刚体）作为引力源，engine 在 applyForces 里对每个有质量非静态体施加 F=GM·m/r²（指向源）；GM 默认 120 使 r=3m 圆轨道周期 2.98s 适合课堂
- 失重实现：matter 0.19 无 body.gravityScale，全局重力施加到每个非静态体，故用「反向力抵消」——统一失重段对所有 `props.g===0` 的 body 施加 `-mass*GRAV.y*GRAV.scale`；ball 的 g 字段控制（g=0 同时 body 加 frictionAir:0 模拟真空）
- 圆轨道验证：v=√(GM/r) 时 symplectic Euler 半隐式积分对向心力漂移 ±5px/200 步内，可接受，无需像 B 场那样解析积分
- 新增预设「行星圆周运动」「椭圆轨道」+ scripts/gravity.mjs 6 断言（圆轨道半径稳定、速率恒定、椭圆远/近地点符合 v<v_circ 的椭圆）

## 20. 第 20 轮：交互与电路修正 + 安培力
- 恒力（constantForce）语义从「每帧就近吸附」改为「持久绑定」：`_target` 一旦确定不重算，目标删除/失效或用户拖走恒力时才重新绑定；overlay 箭头跟随目标刚体，虚线表绑定关系
- 点电荷 mask:0 无碰撞：电荷与极板/感光屏的交互本就走 engine 手动几何检测，关闭 matter 碰撞只消除「点电荷之间、点电荷与块」的推挤，不影响任何教学演示
- 万有引力源（gravity）无刚体，必须在引力段内做「坠入恒星半径内吸收」处理，否则物体会穿过恒星飞走（软化 rPx=max(hypot,20) 是数值防爆手段，不是物理边界）
- metalRod 是「无 E 字段的电动势源」：solve 的 E 默认值 `??3` 只对 battery 成立，对 metalRod 必须 `_eInst ?? 0`（静止 ε=0）；否则 Inspector 渲染（solve 先于 applyForces）时静止杆被当 3V 电源
- 多用电表 mode 用数字 0/1/2 而非字符串（Inspector 的 number+range 控件只吃数字）；「带电测电阻」提示靠检查被测电阻的 currents 是否非零
- 新增安培力演示（电动机/电磁炮方向）：通电金属棒在匀强磁场中受 F=BIL 加速，反电动势 ε=BLv 随速度增大抵消电源电动势，终速 v=E/(BL)

## 21. 第 21 轮：磁铁磁感线 + 传送带旋转
- 磁感线绘制：偶极场 1/r³ 衰减下，绕回 S 极的外部磁感线在离磁铁 100-300px 处场强已降到 1e-4~1e-5，所以场强截断阈值必须 ≤1e-5（原 1e-3 导致「S 极磁感线不显示」）；出射角用「朝向 S 极半球」而非全 360°，否则正前方（背向 S）的最外层磁感线绕到 ~400px 处必然断开
- 磁铁视觉：N 在 +len/2（红）、S 在 −len/2（蓝），overlay 填充色与磁场模型方向必须一致
- 传送带旋转：倾斜传送带（angle≠0）的带面几何 = 中心线沿上方法线上移带体半高（8px），与 matter 刚体上表面一致；接触检测复用 contactIncline（incline.js 对 conveyor 扩展），摩擦用「相对皮带速度」vrel=vt·VEL−belt 判断方向，与水平传送带 supportUnder 分支同一套逻辑
- 带速 belt 的正方向 = 沿带面向下（右端），与 incline 斜面方向 d=(cos a, sin a) 一致；μ>tan a 时带速向上能顶住重力把物块往上送

## 22. 第 22 轮：全方位打磨（逻辑 + 设计）

### 22.1 状态生命周期：三档语义
用户对「清空 / 重置 / 撤销」的期望必须区分清楚，三者不能混：

| 操作 | 元件 | 位置/角度 | 运行态（电荷 Q、电容 U、附着、回旋相位、枪计时、交流瞬时 EMF、恒力绑定） | 历史栈 |
|---|---|---|---|---|
| ⟲ 重置 | 保留 | 回 home | **全部清零**（`resetRuntime`），极板 U 回放置值 | 不动 |
| 清空 | 全删 | — | 随元件消失 | 可撤销 |
| 撤销/重做 | 快照恢复 | 快照 | 快照不含运行态（运行态是"此刻物理"而非"设计"） | 移动指针 |

`resetRuntime()` 的清洗规则：删 `_` 前缀字段（对象级 + props 级），白名单 `{_par,_a,_b}` 是**摆放结构**（并联配对、绳两端）不属于运行态；`props.U` 走 `'U' in component.init` 判定——极板有放置参数就还原，电容器没有就删除；`charge && isStatic` 说明它是「附着在极板/感光屏上被钉住的」，必须 `setStatic(false)` 才能重新运动。
配套约定：`spawn()` 把放置时的完整 props 存进 `component.init`，`resetRuntime` 靠它还原「用户设定的值」而不是硬编码默认值。

### 22.2 角度单位约定（易错）
- `component.angle` / `body.angle` / `home.angle`：**弧度**（matter 原生）
- `component.props.angle`：**度数**（Inspector 滑杆标签是「°」，presets 写 `{angle: 30}`）
- `snapToIncline()` 返回弧度（要给刚体用），`spawn()` 负责换算成 `props.angle` 的度数
- 任何新增的「把角度塞进 props」的代码都必须过这个换算；写反的后果是斜面吸附后元件几乎水平（0.52°），而且撤销一次就回到正确角度——很难复现的幽灵 bug

### 22.3 撤销粒度
- 放置 / 删除 / 改参数 / 拖拽 = 各一个撤销点
- 拖拽靠 `dragIdRef` 去重：同一次手势里连续的 `dragTo` 只在第一次记快照，手势结束（SimCanvas `finish()`）调 `endDrag()` 清标记
- 参数滑杆 800ms 内的连续变化合并成一个撤销点（`update()` 内的时间窗）

### 22.4 顶栏与元件栏的信息密度
- 顶栏分三层：**动作**（选择/撤销/重做/运行/速度）→ **显示**（一个 `👁 显示` 弹出面板 + 偏离默认时亮角标）→ **危险**（清空）。会改变物理结果的开关（失重/忽略电荷力）必须在角标里显式提示，否则用户会怀疑模拟出错
- 元件栏按学科分 tab（力学/电磁/电路/光学），tab 跟随当前工具自动切换；宽屏（≥1100px）撤销 tab、四组平铺——同一份 GROUPS 数据，两种投影
