# 高中物理模拟器（2D 沙盘 Demo）

Vite + React 19 + matter-js 0.20。纯静态 SPA、无后端，`dist/` 直接托管即可（Vercel / Netlify / GitHub Pages / Cloudflare Pages / 局域网 npx serve）。

设计目标：把高中物理真题里的**线条图元**做成可拖放的元件，在平面里自由布置、点运行看现象，数值对齐课本（100 px = 1 m，g = 9.8 m/s²）。

## 运行

```bash
pnpm install
pnpm dev      # 开发服务器
pnpm build    # 构建到 dist/
pnpm test     # 数值回归：电路 6 + 斜面 5 + 场 6 + 轨道 5 + 绳 4 + 单摆 2 + 弹簧/平抛 4 = 32 条断言
pnpm lint     # oxlint src
```

部署：`pnpm build` 后把 `dist/` 传到任意静态托管；本地预览 `npx serve dist -l 8090`。
分享场景不需要后端——`🔗 分享链接` 把场景编码进 URL 的 `#scene=`，对方打开即复原。

## 元件

| 分组 | 元件 |
| --- | --- |
| 力学 | 质点、物块（m、μ、碰撞弹性、初速度）、小球（m、r、弹性）、斜面（θ、长度，画成真题直角三角形）、地面、桌面/轨道、传送带（带速）、恒力 F、弹簧（k、原长）、轻绳（长度，不可伸长）、定滑轮、单摆 |
| 电磁 | 点电荷（q、r）、匀强电场区域（Ex、Ey）、匀强磁场区域（B，⊙/⊗） |
| 电路 | 电池（ε、r）、导线、定值电阻、滑动变阻器、灯泡、开关、电流表、电压表 |
| 光学 | 光源、平面镜、凸透镜、光屏（暂时搁置，仅保留元件） |

每类元件的字段集中在 `src/sim/registry.js`：`defaults()` / `fields` / `body()` / `force()` / `overlay()`，新增元件只改这一个文件 + 一个元件栏条目。

## 交互

- 单指拖空白：平移视角；双指捏合：缩放（0.3–4×）；桌面滚轮缩放
- 点元件：选中并打开属性面板（手机 / 平板为滑入式抽屉）；拖元件：移动
- 选中元件后点空白处：在新位置放置；右下角 ⤢ 显示全部 / ＋ － 缩放 / ⟲ 复位
- 顶部：撤销 ↶ / 重做 ↷ / 运行 / 受力分析 / 重力开关（失重演示）/ 重置 / ❓操作说明 / 清空
- 属性面板：数值框 + 滑杆双输入，可改质量、摩擦、弹性、初速度、旋转角、电路参数；下方实时显示 v / x / y 或 I / U / P
- 场景：`📖 真题预设` 一键载入（平抛 / 斜面 / 带电粒子圆周 / 点电荷相互作用 / 恒力拉物块 / 弹簧振子 / 定滑轮 / 碰撞动量守恒 / 连接体 / 传送带 / 单摆 / 串联电路 / 并联电路），`💾 存场景` 存 localStorage，JSON 导入导出，`🔗 分享链接`，`📷 截图`

## 物理模型要点

- 单位体系：100 px = 1 m，固定 60 Hz 步长；`VEL_SCALE = 0.6`（px/step → m/s），`FORCE_SCALE = 1e-4`（N → matter 力）
- 重力、摩擦、支持力自己算（matter 内摩擦设为 0）：`src/sim/contacts.js` 支持斜面（可含嵌入穿透修正）、地面 / 轨道 / 传送带的动摩擦与静摩擦，静摩擦用本步已施加的外力反推驱动力后 clamp 到 ±μN
- 绳 / 定滑轮 / 单摆：`src/sim/constraints.js` 的 PBD 硬约束（位置投影 + 去径向速度），不会像硬弹簧那样发散
- 磁场：每步把速度矢量精确旋转 φ = qB/m · dt（圆运动半径 r = mv/qB 严格成立）；带电体自己抵消 matter 的重力，无场区不下落
- 电场：F = qE，逐分量施加
- 电路：节点电压法（Norton 等效），端子按 12 px 聚类成节点，支持串并联、短路与断路告警；元件面板实时显示 I / U / P
- 受力分析：重力、支持力、摩擦、恒力、合力，斜面附 mg·sinθ / mg·cosθ 分解与 a = F合/m

## 已知限制

- 只做 2D 平面，3D 磁场斜射入等情形不覆盖
- 物块为矩形、小球为圆，不支持任意多边形碰撞体
- 光学元件已能追迹但界面上暂时搁置
- 滑轮按「离它最近的两个物体」连绳，复杂绳系需手动摆放
